# Roadmap

The roadmap prioritizes reliability before feature count.

## Reliability

- Provider adapter health checks and clearer selector diagnostics.
- More resilient provider-specific response boundaries.
- Better recovery telemetry and sanitized debug export.
- Automated fixture-based DOM regression tests where practical.

## Meetings

- Export transcripts to Markdown and JSON.
- Participant roles such as critic, researcher, engineer, moderator, and summarizer.
- Configurable meeting goals and finish conditions.
- Optional approval-before-send mode.
- Improved routing while preserving deterministic fallback.

## Experience

- Cleaner onboarding for first-time installation.
- Sanitized demo/recording workflow for README media.
- Meeting templates for debate, code review, research, and product strategy.

## Providers

New providers should be added only when they can preserve Lee Relay's core contract: observable send/delivery/response evidence rather than blind timing-based automation.
